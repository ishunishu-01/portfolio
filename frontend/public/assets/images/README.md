# Website Images Folder

This folder stores all **website-related images** — things used in the design of the site itself (not your personal content).

## Subfolders

| Folder         | Purpose |
|----------------|---------|
| `backgrounds/` | Background images, textures, patterns used across pages |
| `icons/`       | Custom icon images, logo variants, favicon sources |
| `banners/`     | Hero banners, section banners, OG (Open Graph) social preview images |

## Naming Convention
- Use lowercase with hyphens: `hero-bg.jpg`, `og-preview.png`
- Use descriptive names: `about-banner.webp`, `skills-bg-pattern.svg`

## Recommended Formats
| Use Case        | Format |
|-----------------|--------|
| Photos          | `.jpg` / `.webp` |
| Transparent art | `.png` / `.webp` |
| Icons/Logos     | `.svg` (preferred) |
| Animations      | `.gif` / `.webp` |

## Example Structure
```
public/
  assets/
    images/
      backgrounds/
        hero-bg.jpg
        section-pattern.svg
      icons/
        logo.svg
        favicon-512.png
      banners/
        og-preview.png      ← 1200×630px for social sharing
        about-banner.jpg
```
